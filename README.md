# 🎓 SkillSphere – Online Learning Platform

A modern online learning platform where users can explore courses, view details, and enroll in skill-based programs like Web Development, Design, Marketing, AI, and more.

---

## 🌐 Live Demo

👉 Live URL: https://a8-skill-sphere.vercel.app/

---

## 📌 Project Purpose

SkillSphere is built to provide a simple and interactive learning experience for students.  
Users can browse courses, search content, view detailed course information, and manage their profile with authentication support.

---

## ✨ Key Features

- 🔐 User Authentication (Login/Register)
- 🔍 Course Search Functionality
- 📚 All Courses Listing Page
- 📖 Course Details Page (Protected Route)
- 👤 My Profile Page with Update Feature
- 🎥 Hero Section with Banner/Slider
- 🔥 Popular & Trending Courses Section
- 🧑‍🏫 Top Instructors Section
- 📱 Fully Responsive Design (Mobile, Tablet, Desktop)
- ⚡ Fast Page Navigation using Next.js App Router
- 🔔 Toast Notifications for Actions
- 🧭 Persistent Navbar & Footer
- ❌ Custom 404 Not Found Page
- ⏳ Loader while fetching data

---

## 🛠️ Tech Stack

- ⚛️ Next.js (App Router)
- 🎨 Tailwind CSS
- 🧩 DaisyUI
- 🔐 Better Auth
- 🎞️ Swiper JS (Slider)
- 🔔 React Hot Toast
